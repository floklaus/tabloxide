  • None

The horizontal axis has values that repeat. The chart shows the sum for each value.

Each column of the vertical axis has its own aggregate. The message shows one time, when the chart sets the aggregate.

The controls below the column depend on its type. A number column has no control. The same limit applies to a series column, in place of the fixed limit of 8 series.

4. Chart type: a type that cannot work gives the cause

Chart type

Scatter plot. It needs two number columns. This result has one.

A type that cannot work keeps the focus and has no action. The focus or the pointer shows the cause. A change of the type keeps the columns that the new type can use.

5. A warning at its cause

Vertical axis

20 cells of price are not numbers, for example $10. The chart does not show them.

A warning about one column is below that column, with a mark in the control. A note about the complete result stays above the chart, for example "Chart of the first 500 rows".
