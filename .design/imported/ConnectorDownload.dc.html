Download the MongoDB connector?

MongoDB is not built in. A connector is a separate program that connects Tabloxide to MongoDB.

Engine
MongoDB
Version
[0.1.0]
Size
[14 MB]
Source
The list of connectors at tabloxide.org. The file comes from the GitHub releases of the Tabloxide project.
Check
Tabloxide checks the checksum and the signature before it keeps the file.
The connector runs as a program with your permissions. It gets the address and the password of each MongoDB connection.

Tabloxide sends no request for connectors before you select Download.
